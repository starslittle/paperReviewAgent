# 图文一致性判断原因分析

## 问题现象

在审查报告中，部分"图文一致性问题"出现以下情况：
1. **原文片段/描述**只显示"3."或"4."等极简内容
2. **修改理由**显示"决策=优先改文。rule3(图像证据强度高于文字主张)。strengths(text=0.00, image=0.35)"
3. 部分问题有详细描述（如"图片为流程图,但角色未知"），部分只有"4."

## 原因分析

### 1. 为什么"原文片段"会变成"3."或"4."？

**根本原因：文档中的图号引用过于简短**

Vision Agent 提取"原文片段"（quote）的流程：

```
_extract_reference_sentences() 
  → 通过正则匹配找到包含图号的句子（如"图3"、"Figure 3"）
  → 如果文档中只有"图3"或"3."这样的简短引用，匹配到的句子就会很短

_select_reference_sentence()
  → 优先使用 role_assignment.evidence_sentence
  → 如果没有，使用 figure_node.image_scope_text
  → 再没有，使用 figure_node.references[0].sentence
```

**具体场景：**
- 文档中可能只有"图3"、"3."、"如图3所示"这样的简短引用
- 没有详细的描述性文字（如"如图3所示，实验流程包括样本处理、数据分析等步骤"）
- 因此提取到的 `evidence_sentence` 或 `reference_sentence` 就是"3."这样的极简内容

**代码位置：**
- `agent/vision_agent.py:1114-1123` - `_select_reference_sentence()` 方法
- `agent/vision_agent.py:691-725` - `_extract_reference_sentences()` 方法

---

### 2. 为什么会出现"图像证据强度高于文字主张"的判断？

**根本原因：文字强度（text_claim_strength）过低，图像强度（image_evidence_strength）相对较高**

**强度计算逻辑：**

```python
# agent/vision_agent.py:1646-1660
def _compute_claim_strengths(role_assignment, image_capacity):
    text_claim_strength = 0.5  # 默认值
    image_evidence_strength = 0.5  # 默认值
    
    # 文字强度 = role_assignment.confidence（图像角色识别的置信度）
    if role_assignment.confidence is not None:
        text_claim_strength = role_assignment.confidence  # 范围 0.0-1.0
    
    # 图像强度 = 基于 image_capacity.sufficient（图像信息容量是否足够）
    if image_capacity.sufficient:
        image_evidence_strength = 0.85  # 图像信息充足
    elif image_capacity and not image_capacity.sufficient:
        image_evidence_strength = 0.35  # 图像信息不足但仍有一定信息
```

**触发 rule3 的条件：**

```python
# agent/vision_agent.py:137-144
if i_strength > t_strength:  # 图像强度 > 文字强度
    signals.append({
        "rule": "rule3",
        "target": MODIFY_TEXT,  # 优先改文
        "detail": "图像证据强度高于文字主张",
    })
```

**典型场景：**

| 情况 | text_claim_strength | image_evidence_strength | 结果 |
|------|---------------------|-------------------------|------|
| **场景1**：引用句只有"3."，无法识别图像角色 | 0.0 | 0.35 | ✅ 触发 rule3，优先改文 |
| **场景2**：引用句简短，角色识别置信度低 | 0.1 | 0.85 | ✅ 触发 rule3，优先改文 |
| **场景3**：引用句详细，角色识别置信度高 | 0.8 | 0.35 | ❌ 不触发 rule3，可能优先改图 |

**为什么会出现这种情况：**

1. **引用句过于简短**：
   - 文档中只有"图3"、"3."这样的引用
   - 没有描述图像内容的文字（如"如图3所示的实验流程"）
   - 导致 `role_assignment.confidence` 很低（0.0-0.1）

2. **图像本身包含信息**：
   - 图像可能是流程图、数据表、架构图等，本身包含一定信息
   - `image_capacity.sufficient` 可能为 `True`（图像信息充足）或 `False`（不足但仍有一定信息）
   - 因此 `image_evidence_strength` 为 0.85 或 0.35

3. **强度对比结果**：
   - `image_evidence_strength (0.35/0.85) > text_claim_strength (0.0/0.1)`
   - 触发 rule3："图像证据强度高于文字主张"
   - 决策：优先改文（MODIFY_TEXT）

### 3. 为什么有些问题有详细描述，有些只有"4."？

**原因：不同问题类型使用不同的 quote 来源**

Vision Agent 生成问题时，`quote` 字段的来源不同：

| 问题类型 | quote 来源 | 代码位置 |
|---------|-----------|---------|
| **角色识别失败** | `role_assignment.evidence_sentence` 或默认文本 | `vision_agent.py:1539` |
| **阶段不匹配** | `stage_alignment.message` | `vision_agent.py:1561` |
| **图像容量不足** | `image_capacity.reason` | `vision_agent.py:1575` |
| **证据外推** | `reference_sentence`（引用句） | `vision_agent.py:555` |

**具体说明：**

1. **有详细描述的问题**：
   - 来自 `image_capacity.reason`：如"图片为流程图,但角色未知;若用于论证系统执行逻辑,则信息容量足够..."
   - 来自 `stage_alignment.message`：如"图像偏结果类图表，但文本偏方法/设计描述..."
   - 这些是 AI 分析后生成的详细描述

2. **只有"4."的问题**：
   - 来自 `role_assignment.evidence_sentence` 或 `reference_sentence`
   - 如果文档中引用句只有"图4"或"4."，提取到的就是"4."
   - 这是直接从文档中提取的原文片段，没有经过 AI 扩展

## 解决方案建议

### 1. 改进 quote 提取逻辑

**问题**：当引用句过短时，应该扩展上下文或使用更智能的提取方式。

**建议**：
- 如果提取到的引用句过短（如只有"3."、"图3"），尝试提取该句子所在段落的更多内容
- 或者使用 `image_capacity.reason` 或 `stage_alignment.message` 作为 quote 的补充

### 2. 优化强度计算

**问题**：当引用句过短导致 `text_claim_strength` 过低时，可能误判。

**建议**：
- 如果 `evidence_sentence` 过短（如少于10个字符），可以设置一个最小阈值（如 0.2），避免 text_claim_strength 为 0.0
- 或者在这种情况下，优先使用 `image_capacity.reason` 等更详细的信息来判断

### 3. 改进问题描述

**问题**：当 quote 只有"3."时，用户无法理解问题所在。

**建议**：
- 如果 quote 过短，优先使用 `image_capacity.reason` 或 `stage_alignment.message` 作为问题描述
- 或者在 quote 后追加详细说明，如"3.（引用句过短，无法识别图像角色）"

---

## 总结

1. **"3."或"4."的出现**：因为文档中图号引用过于简短，Vision Agent 提取到的引用句就是这些简短内容。

2. **"图像证据强度高于文字主张"**：因为引用句过短导致文字强度（text_claim_strength）很低（0.0-0.1），而图像本身有一定信息量（image_evidence_strength=0.35/0.85），强度对比触发 rule3。

3. **详细描述 vs 简短描述**：不同问题类型使用不同的 quote 来源，有些来自 AI 分析（详细），有些直接来自文档原文（简短）。

**核心问题**：文档中图号引用过于简短，缺乏描述性文字，导致 Vision Agent 无法充分理解图像在论证中的作用，从而产生"优先改文"的判断。
