## 摘要写作要求

### 内容结构（必须按此顺序）

```
1. 研究背景（为什么做）
   - 说明研究问题、现状、意义
   - 例如："随着XX技术的发展，XX领域面临XX问题..."

2. 技术方案/功能介绍（怎么做、做了什么）
   - 说明采用的技术栈、方法、系统架构
   - 说明实现的主要功能模块
   - 例如："采用Spring Boot + Vue架构，实现了XX、XX、XX等功能..."

3. 研究成果（做得怎么样）
   - 说明测试结果、系统效果、性能指标
   - 例如："经测试，系统运行稳定，功能完备..."
```

### 关键词要求（严格）

- **数量**：不少于4个（中英文均要求）
- **格式**：
  - 中文：`关键词：XXX；XXX；XXX；XXX`（中文冒号）
  - 英文：`Keywords: XXX; XXX; XXX; XXX`（K大写）
- **内容**：必须与论文主题相关

---

## 常见问题与修改建议

### 问题1：关键词少于4个

**检测结果：**
```
问题：关键词数量不足（仅3个）
严重程度：High
```

**修改建议：**
- 补充与论文主题相关的关键词
- 确保中英文摘要的关键词数量都≥4个

### 问题2：关键词格式错误

**检测结果：**
```
问题：英文关键词"Key words"应为"Keywords"
严重程度：Low
```

**修改建议：**
- 英文：`Key words:` → `Keywords:`（K大写，单词连写）
- 中文：`关键词:` → `关键词：`（使用中文冒号）

### 问题3：关键词与主题无关

**检测结果：**
```
问题：关键词中包含"Red Scenic Spots"，与论文主题"零食仓库管理"无关
严重程度：High
```

**修改建议：**
- 删除无关关键词
- 替换为与论文主题直接相关的词汇

### 问题4：摘要结构不完整

**检测结果：**
```
问题：摘要缺少研究背景部分
严重程度：High
```

**修改建议：**
- 在摘要开头补充研究背景
- 说明为什么要做这个研究、解决什么问题

### 问题5：摘要顺序混乱

**检测结果：**
```
问题：技术方案出现在研究背景之前
严重程度：Medium
```

**修改建议：**
- 调整段落顺序：先背景、再技术、最后成果
- 确保逻辑流畅

## 算法类 vs 系统类论文摘要示例

### 算法类论文摘要（标准）

```
【研究背景】随着深度学习在图像识别领域的广泛应用，现有的卷积神经网络模型在处理
小目标检测时准确率较低，尤其在复杂背景下容易出现漏检和误检问题。

【技术方案】本文提出了一种改进的YOLO算法，通过引入注意力机制和多尺度特征融合
策略，增强了模型对小目标的特征提取能力。算法的时间复杂度为O(n²)，空间复杂度为O(n)。

【实验成果】在COCO数据集上进行实验，相比baseline YOLOv5，本文算法在小目标检测
的mAP指标上提升了3.2%，达到了78.5%，同时推理速度保持在45FPS。

关键词：YOLO算法；注意力机制；小目标检测；特征融合
```

**要点：**
- ✅ 包含算法改进点（注意力机制、多尺度特征融合）
- ✅ 包含复杂度分析（时间O(n²)、空间O(n)）
- ✅ 包含性能指标（mAP提升3.2%，达到78.5%）
- ✅ 包含数据集（COCO）
- ✅ 关键词包含算法名称和方法名称

### 系统类论文摘要（标准）

```
【研究背景】随着电商行业的快速发展，传统的库存管理方式效率低下，难以满足日益
增长的业务需求，亟需一个高效的仓库管理系统来提升管理效率。

【技术方案】本文设计并实现了一个基于Spring Boot + Vue的仓库管理系统。系统采用
BS架构，前端使用Vue.js构建响应式界面，后端采用Spring Boot框架实现RESTful API，
数据存储使用MySQL数据库。系统实现了商品管理、库存管理、出入库管理、供应商管理
等核心功能模块。

【测试成果】经过功能测试、性能测试和用户测试，系统在1000并发情况下响应时间小于
200ms，各项功能运行稳定，用户满意度达90%以上。

关键词：Spring Boot；Vue.js；仓库管理系统；库存管理
```

**要点：**
- ✅ 包含技术栈（Spring Boot + Vue + MySQL）
- ✅ 包含系统架构（BS架构）
- ✅ 包含功能模块（至少3-4个）
- ✅ 包含测试结果（并发性能、响应时间、满意度）
- ✅ 关键词包含核心技术栈

## 问题严重程度说明

| 级别 | 说明 | 示例 |
|------|------|------|
| **High（严重）** | 必须修改，影响论文质量 | 关键词少于4个，缺少研究背景，关键词与主题无关 |
| **Medium（中等）** | 建议修改，影响论文规范性 | 摘要顺序混乱，关键词部分不符 |
| **Low（轻微）** | 可选修改，不影响核心内容 | 格式错误（冒号类型、大小写），表述可优化 |
